| Блок | Что сделано | Статус |

| **Боеприпасы для всего дистанционного оружия** | Луки, арбалеты, мушкеты, пистоли, револьверы, винтовки, дробовики, тесла, автоматическое, импульсное, плазменное; 16 типов по эпохам, особые свойства; магазин, крафт, добыча, дом; умения оружия платят патронами | ✅ |
| **Перезарядка** | Кнопка на сенсорном HUD, прерывание уклонением / оглушением / выстрелом / сменой оружия без потерь и дублей, автоперезарядка в настройках | ✅ |

| **Зелья маны** | Малое, обычное, большое, редкий эликсир; общая перезарядка 8 с; кнопка на HUD | ✅ |
